# Conversational AI Platform Architecture

Executable reference architecture for enterprise conversational AI platforms with agents, MCP, RAG, WhatsApp, transactional systems, internal security, and end-to-end observability.

!!! warning "Synthetic banking data"
    The **debt renegotiation** and **credit card** journeys use test-only data, reserved tax IDs, and responses generated by `core-bancario-mock`. No real financial information, contract, invoice, or banking transaction is processed. In the target architecture, the mock must be replaced by real, governed Banking Core APIs while preserving functional contracts, identity controls, authorization, idempotency, auditability, and observability.

## Conversational journey

| Stage | Responsibility |
|---|---|
| Entry | BFF validates signatures and guarantees durable ingress |
| Orchestration | Orchestrator controls Inbox, state, and Outbox |
| Reasoning | Agent Runtime decides the next action |
| Tools | Tool Service applies identity and policy |
| Domain | Renegotiation Service revalidates and coordinates the Core |
| Core | The mock provides synthetic data; in the target architecture, real banking APIs validate caller/tenant and protect mutable operations |
| Support | Memory, knowledge, audit, and handoff complete the experience |

## Stack and patterns

| Capability | Technology or pattern |
|---|---|
| Services | .NET, Python, hexagonal architecture, and REST |
| Agents | Strands, OpenAI, and MCP |
| Messaging | Kafka, Inbox/Outbox, and idempotency |
| Knowledge | Vector OpenSearch |
| State | PostgreSQL, MongoDB, and Redis |
| Security | HMAC, pair-specific JWTs, signed tenant context, and governed tools |
| Observability | OpenTelemetry, Alloy, Prometheus, Alertmanager, Grafana, Loki, and Jaeger |
| Supply chain | Trivy, SARIF, and SPDX SBOM |
| Execution | Docker Compose, GitHub Actions, k6, and drill scripts |

!!! success "Executable architecture"
    The project records real validation runs, infrastructure smoke tests, and a coordinated E2E workflow across 12 services using synthetic datasets and a mocked Banking Core.
